# On the day

One page. Print it.

## The week before

- [ ] Run the whole thing once with every tablet, on the network you'll use in the room.
- [ ] Check the run sheet order and every item's wording against the script (`content.json`). Check each film cue names the right film.
- [ ] In Bunny, add this app's address to the library's allowed domains (Stream → library → Security). Then open the observer page (`/watch`) on each computer and screen the observers will use, tap a film cue, and watch it play with sound.
- [ ] Film a tablet under the lights. If the white time-up screen throws light on faces, ask for it to stay dark.

## The night before

For each tablet:

- [ ] Charged. Table name on a label on the back.
- [ ] Open its table's link (Game master → Setup → Link) and add it to the home screen.
- [ ] Auto-Lock: Never. Do Not Disturb: on. Automatic updates: off.
- [ ] Guided Access on, so it can't leave the app.

Pack: stands, a charger or power bank per table, one spare tablet already set up, a mobile hotspot, the printed backup pack (one envelope of posts and notes per day, per table), this page, the paper run sheet.

Game master → Setup → **Reset for the real run**.

## In the room (about 20 minutes)

1. Tablets on their stands, on power. Tap the home-screen icon. Each shows its table's name.
2. Each observers' screen: open `/watch` in Chrome, full screen, tap **Start with sound**. Game master → Run → Observers shows how many are watching.
3. Game master → Run → Tables: every table has a lit dot. Tap **Identify**: each tablet shows its name large.
4. Test: tap **Next** until a clock is running, check a tablet, tap **End**. Under Observers, play any film and check every observers' screen shows it with sound, then **Stop film**.
5. Setup → **Reset for the real run**. Hands off the tablets.

## Running it

Tap **Next**. That's the job. The run sheet under it shows where you are.

When Next says **Film**, tap it as the film starts on the main screen: that starts the same film on the observers' monitor. Whoever looks after the observers' screens turns Zoom's sound down until the film ends, so they don't hear it twice.

After Decide, the button turns into the choices. Tap what the room decided. The next day's first line then tells you which version of the bulletin to play.

- Round running long or short: **−1 min / +1 min**.
- Need to stop the clock: **Pause**, then **Resume**.
- Something extra to say: type it under "More to send".
- Tapped the wrong thing: **Recall** the item, or tap the right line in the run sheet.
- Started the wrong film for observers: **Stop film** (under Observers), then tap the right line.

One person drives. A second has the game master page open on another device and touches nothing.

## If it goes wrong

| What | Do this |
|---|---|
| Amber dot on a tablet | It lost the connection and is still counting. Leave it; it reconnects by itself |
| Venue internet gone | Join the tablets to the hotspot |
| A tablet dies | Swap in the spare, open that table's link |
| A film won't play on an observers' screen | If it says **Tap to play the film**, tap it. Otherwise reload the page and tap **Start with sound**; it joins the film where it is. Failing that, they watch it over Zoom |
| Game master phone dies | The second device takes over |
| Nothing works | Phone timer, paper envelopes, carry on |
